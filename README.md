# AI3連単

ボートレースの3連単予想ゲームです。

## 遊び方
1. ボートレース場を選択する
2. STARTボタンを押す
3. ルーレットが回り、3着→2着→1着の順に結果が決定される

## データについて
- データ出典: 艇国DB
- 集計期間: 2025年8月1日～2026年7月31日
- このゲームにおける「コース＝艇番」はゲーム上の簡易モデルであり、実際のレース予想を保証するものではありません。

## 公開URL
現在、GitHub Pagesによる公開を準備中です。

## 現在の機能

- 3連単予想ルーレット
- AIタカシによるコメント返信機能
- ユーザー名入力（未入力時は「匿名」）
- Supabase連携によるコメント永続保存と履歴表示

## 将来の実装予定

1. **予想結果との紐付け**
   - 予想結果（アタリ/ハズレ）とユーザーコメント、AIタカシの返信をセットで表示・記録できるようにします。
2. **AIタカシのAI化**
   - 将来的にはAI APIを利用し、コメント内容に応じた自然な返信を生成できるようにします（APIキー管理は安全な構成を優先します）。
